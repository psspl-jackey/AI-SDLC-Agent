# Answer key: ecommerce_brief.md

Planted gaps the agents should find:

- SOW gap: "The app should be fast" is vague (no measurable target).
- SOW gap: "Launch before Diwali" has no year or date; timeline feasibility unknown.
- SOW gap: platforms not stated (Android, iOS or both).
- SOW gap: login method not stated.
- NFR gap: no expected user scale.
- NFR gap: no data privacy or account deletion requirement (DPDP Act, India).
- Domain checklist gap (table stakes): search and filters missing.
- Domain checklist gap (table stakes): returns and cancellations missing.
- Domain checklist gap (table stakes): order and delivery notifications missing.
- Domain checklist gap (table stakes): order tracking missing.
- Domain checklist gap (common): ratings and reviews, coupons, GST invoice.
- Scope rule: online payment must be built against a dummy gateway (real payment is out of scope).

Requirements a senior analyst would extract: browse by category; product detail with photos, price,
fabric, weaver; cart; place order; checkout with dummy payment; order history; admin product
management; admin order view.
